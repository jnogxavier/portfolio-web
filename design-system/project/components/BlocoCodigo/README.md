Código de verdade, e só isso: YAML, HCL, shell, saída de terminal.

Spline Sans Mono existe neste sistema para esta peça. Monoespaçada como rótulo decorativo é um dos tiques mais reconhecíveis de página gerada, então `linguagem` renderiza em `meta`, na Archivo — o rótulo descreve o código, não é código.

Linha longa faz o bloco rolar na horizontal. A página nunca alarga por causa dele. Não quebre linha de configuração para caber. YAML quebrado errado é YAML errado.

Sem destaque de sintaxe. Seria a primeira biblioteca do sistema e ainda não se paga.
