O fim de toda página. Estado, endereço, e os caminhos alternativos.

O endereço é texto selecionável, sempre. `mailto:` é conveniência que falha em muito contexto, e um site onde o único caminho para falar com você é um link que não abre é um site sem contato. O botão de copiar tenta a área de transferência e, se o navegador recusar, seleciona o texto para a pessoa copiar na mão.

Nunca formulário sozinho. Formulário esconde o endereço e some com a mensagem se o backend falhar.

O estado vem de `EstadoPill` e precisa ser verdade. "Disponível para conversar" numa página de alguém que já fechou contrato é pior do que não ter pílula nenhuma.

Os links são caminhos alternativos, não enfeite: currículo em PDF, GitHub, LinkedIn. Um por linha de raciocínio, sem ícone e sem seta no texto.
