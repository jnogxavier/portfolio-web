# jnogxavier-portfolio

Site de portfólio pessoal. Ainda não tem site: por enquanto este repositório guarda o design system que vai governá-lo.

## O que tem aqui

- `design-system/project/` — a fonte do design system. É a mesma coisa publicada no artifact "jnogxavier" no claude.ai, versionada aqui para não existir só lá.
- `.impeccable.md` — o contexto de design do projeto: para quem é, que voz tem, o que não pode parecer.

## A regra que organiza o conteúdo

É portfólio, não currículo em HTML. Cada trabalho é contado como caso, nesta ordem: o problema, o que eu fiz, o que troquei pelo quê, o resultado medido, e o que eu faria diferente. O número fecha o caso, nunca abre.

O currículo existe à parte, em PDF, e serve a outro leitor.
